# Security Policy

Reporting a Vulnerability

If you discover an error:

DO NOT open a public issue.

Email directly to:
contact@aikungfu.dev

## About this server's security

The controls and limits of this server (the person's own confirmation of each payment through the client where it supports prompts, a per-payment cap, a session budget, an optional recipient allowlist and an audit log) are described in the README. They are a self-assessment, not an audit or a certification. Responses include fields returned by Safaricom and Africa's Talking: treat them as untrusted data. Keep your MCP client's per-call approval on for the money-out tools. You can scan this server's tool descriptions with `uvx mcp-scan`.
